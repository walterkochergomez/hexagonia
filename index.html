Hexagonia no se pudo cargar

Si ves esto en GitHub Pages, el sitio está mostrando el código sin compilar. En el repositorio ve a Settings → Pages → Build and deployment → Source y elige GitHub Actions. Después, en la pestaña Actions, abre «Publicar en GitHub Pages» y pulsa Run workflow.

On GitHub Pages this means the uncompiled source is being served: set Settings → Pages → Source to “GitHub Actions”, then run the “Publicar en GitHub Pages” workflow from the Actions tab.
